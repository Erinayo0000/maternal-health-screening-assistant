# Maternal Health Screening Assistant

## Version

Current Version: **0.1**

---

## Project Overview

The Maternal Health Screening Assistant is a Python application designed to help healthcare workers quickly screen pregnant women for potential danger signs during antenatal visits.

The application provides a fast, simple, and offline screening tool that helps identify patients who may require urgent medical assessment.

This project is part of **Project Asteria**, a long-term initiative to build AI-powered healthcare solutions that improve maternal health outcomes, particularly in low-resource settings.

---

## Problem Statement

Maternal mortality remains a major challenge in many low-resource communities because warning signs are sometimes missed or not identified early enough.

Healthcare workers need a simple, reliable, and easy-to-use screening tool that helps them recognize high-risk pregnancies during routine antenatal visits.
